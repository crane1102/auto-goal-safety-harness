# Issue Reporting Guide

A useful report includes:

1. operating system and Python version;
2. exact command used;
3. minimal input text and explicit metadata;
4. expected classification and observed classification;
5. whether the process exited cleanly;
6. a minimal reproducer or regression test.

Please redact credentials, personal data, session identifiers, and production paths. Safety reports should explain whether the issue can block ordinary messages, resume stale state, create an unbounded loop, or leak audit data.
